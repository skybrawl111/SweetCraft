[ORM-запрос]:
qs1 = Filling.objects.filter(
    is_active=True,
    price_per_kg__gte=Decimal('1200.00'),
    price_per_kg__lte=Decimal('1500.00')
).order_by('price_per_kg')

ЗАПРОС 3: АГРЕГАЦИЯ ДАННЫХ (Расчет финансово-производственных показателей)
--------------------------------------------------------------------------------
Бизнес-задача: Посчитать сводную статистику по подтвержденным заказам: количество, суммарную выручку, средний чек и максимальную стоимость заказа.

[ORM-запрос]:
qs3 = Order.objects.filter(
    status__in=['ACCEPTED', 'IN_PROGRESS', 'READY', 'COMPLETED']
).aggregate(
    total_orders=Count('id'),
    total_revenue=Sum('total_price'),
    avg_check=Avg('total_price'),
    max_order=Max('total_price')
)

[Сгенерированный SQL агрегации]:
SELECT COUNT("bakery_order"."id") AS "total_orders", (CAST(SUM("bakery_order"."total_price") AS NUMERIC)) AS "total_revenue", (CAST(AVG("bakery_order"."total_price") AS NUMERIC)) AS "avg_check", (CAST(MAX("bakery_order"."total_price") AS NUMERIC)) AS "max_order" FROM "bakery_order" WHERE "bakery_order"."status" IN ('ACCEPTED', 'IN_PROGRESS', 'READY', 'COMPLETED')

[Результат выполнения агрегации]:

3. Средний чек клиента кондитерской:  6149.24 руб.
4. Максимальная стоимость заказа:      9650.00 руб.

ЗАПРОС 4: ВЫБОРКА ПО СВЯЗИ «ОДИН КО МНОГИМ» (select_related без проблемы N+1)
--------------------------------------------------------------------------------
Бизнес-задача: Загрузить позиции заказов со статусом ACCEPTED сразу с присоединенными объектами Заказа, Клиента, Коржа и Начинки через единый SQL JOIN.

[ORM-запрос]:
qs4 = OrderItem.objects.select_related(
    'order', 'order__customer', 'crust_type', 'filling'
).filter(order__status='ACCEPTED')[:5]

[Сгенерированный SQL с INNER JOIN]:
SELECT "bakery_orderitem"."id", "bakery_orderitem"."order_id", "bakery_orderitem"."base_cake_id", "bakery_orderitem"."crust_type_id", "bakery_orderitem"."filling_id", "bakery_orderitem"."tiers", "bakery_orderitem"."weight", "bakery_orderitem"."item_price", "bakery_orderitem"."text_on_cake", "bakery_order"."id", "bakery_order"."customer_id", "bakery_order"."delivery_date", "bakery_order"."status", "bakery_order"."total_price", "bakery_order"."contact_phone", "bakery_order"."delivery_address", "bakery_order"."comment", "bakery_order"."created_at", "bakery_order"."updated_at", "bakery_customuser"."id", "bakery_customuser"."password", "bakery_customuser"."last_login", "bakery_customuser"."is_superuser", "bakery_customuser"."username", "bakery_customuser"."first_name", "bakery_customuser"."last_name", "bakery_customuser"."email", "bakery_customuser"."is_staff", "bakery_customuser"."is_active", "bakery_customuser"."date_joined", "bakery_customuser"."role", "bakery_customuser"."phone", "bakery_crusttype"."id", "bakery_crusttype"."name", "bakery_crusttype"."extra_cost", "bakery_crusttype"."description", "bakery_filling"."id", "bakery_filling"."name", "bakery_filling"."description", "bakery_filling"."price_per_kg", "bakery_filling"."is_active" FROM "bakery_orderitem" INNER JOIN "bakery_order" ON ("bakery_orderitem"."order_id" = "bakery_order"."id") INNER JOIN "bakery_customuser" ON ("bakery_order"."customer_id" = "bakery_customuser"."id") INNER JOIN "bakery_crusttype" ON ("bakery_orderitem"."crust_type_id" = "bakery_crusttype"."id") INNER JOIN "bakery_filling" ON ("bakery_orderitem"."filling_id" = "bakery_filling"."id") WHERE "bakery_order"."status" = ACCEPTED ORDER BY "bakery_orderitem"."id" ASC LIMIT 5

ЗАПРОС 5: ВЫБОРКА ПО СВЯЗИ «МНОГИЕ КО МНОГИМ» (prefetch_related для M:M и 1:M)
--------------------------------------------------------------------------------
Бизнес-задача: Загрузить торты категории «Классические торты» с предварительной пакетной выборкой всех совместимых начинок (M:M) и отзывов клиентов (1:M).

[ORM-запрос]:
qs5 = BaseCake.objects.prefetch_related(
    'available_fillings', 'reviews'
).filter(category__slug='classic-cakes')[:5]

[Количество выполненных SQL-запросов]: 3 (вместо N+1)
  SQL [1]: SELECT "bakery_basecake"."id", "bakery_basecake"."category_id", "bakery_basecake"."title", "bakery_basecake"."slug", "bakery_basecake"."description", "bakery_basecake"."base_price", "bakery_basecake"."default_weight", "bakery_basecake"."crust_type_id", "bakery_basecake"."image", "bakery_basecake"."is_available", "bakery_basecake"."created_at" FROM "bakery_basecake" INNER JOIN "bakery_category" ON ("bakery_basecake"."category_id" = "bakery_category"."id") WHERE "bakery_category"."slug" = 'classic-cakes' ORDER BY "bakery_basecake"."created_at" DESC LIMIT 5
  SQL [2]: SELECT ("bakery_basecake_available_fillings"."basecake_id") AS "_prefetch_related_val_basecake_id", "bakery_filling"."id", "bakery_filling"."name", "bakery_filling"."description", "bakery_filling"."price_per_kg", "bakery_filling"."is_active" FROM "bakery_filling" INNER JOIN "bakery_basecake_available_fillings" ON ("bakery_filling"."id" = "bakery_basecake_available_fillings"."filling_id") WHERE "bakery_basecake_available_fillings"."basecake_id" IN (5, 4, 3, 2, 1) ORDER BY "bakery_filling"."name" ASC
  SQL [3]: SELECT "bakery_review"."id", "bakery_review"."base_cake_id", "bakery_review"."customer_id", "bakery_review"."rating", "bakery_review"."text", "bakery_review"."created_at" FROM "bakery_review" WHERE "bakery_review"."base_cake_id" IN (5, 4, 3, 2, 1) ORDER BY "bakery_review"."created_at" DESC
