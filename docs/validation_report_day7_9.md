## 3. Реализация требований Занятия 9 (Формы и клиентская логика)

| Требование ТЗ | Реализация в проекте «SweetCraft» |
| :--- | :--- |
| **Django Forms & CSRF** | Все формы (`CustomCakeOrderForm`, `ReviewForm`, `UserLoginForm`) используют `ModelForm` / `Form`, содержат обязательный `{% csrf_token %}`, серверную валидацию `clean()`, сохранение введённых данных при ошибке, сообщения `django.contrib.messages` и безопасный `redirect`. |
| **Серверная валидация рядом с полями** | Ошибки каждого поля выводятся в блоках `.form-error` непосредственно под соответствующим элементом ввода. |
| **Клиентская валидация (JS)** | В `static/js/main.js` реализованы маска телефона `+7 (XXX) XXX-XX-XX`, регулярное выражение для e-mail, проверка минимальной длины отзыва и обязательных полей до отправки. |
| **Динамические элементы без перезагрузки** | 1. Интерактивный слайдер веса и калькулятор стоимости в конструкторе.<br>2. Живой фильтр каталога и поиск по названию в реальном времени.<br>3. Переключение мобильного меню-гамбургера. |
| **Асинхронный fetch к JSON API** | Вызов `fetch('/api/check-date-and-price/?...')` при изменении параметров заказа торта: автоматическая проверка суточного лимита цеха (35 кг) и расчет итоговой стоимости с анимацией спиннера `#calc-spinner`. |

## 4. Сравнение страниц с макетом Figma (Занятие 6)

1. **Цветовая палитра и типографика:**
   - Строгое соответствие UI-Kit из Занятия 6: Шоколадный Primary `#4A2C11`, Карамельный Accent `#D97706`, Фон Сливочный `#FAF9F6`, темный текст `#1F2937`, рамки `#E5E7EB`.
   - Семейство шрифтов: Inter, sans-serif с базовой сеткой 8-pt (`gap: 16px`, `padding: 24px`, `border-radius: 8px`).

2. **Главная страница (`/`):**
   - Точно воссоздан Hero-блок с кнопкой призыва к действию (CTA), блок УТП кондитерской с иконками, витрина хитов продаж и лента свежих отзывов покупателей.

3. **Интерактивный конструктор торта (`/builder/`):**
   - Соответствует макету: выбор коржа с превью, начинки с ценой за кг, чекбоксы декораций, ползунок веса (1.0–15.0 кг) и карточка расчёта с предупреждением о лимите мощности цеха.

4. **Адаптивность:**
   - 1440px: полноценный десктопный макет в 3–4 колонки с развернутым меню.
   - 375px: мобильная колоночная верстка (1 колонка), всплывающее меню-шторка, увеличенные области клика (touch targets $\ge 44 \times 44$ px).
